# 首版实现规格

## 已确认范围

- 手机浏览器通过 localhost 使用，服务运行在原生 Termux。
- 添加已有目录作为项目，按项目列出 Codex 历史会话并分页。
- 新建、恢复会话，流式消息、工具活动、停止执行、处理审批和输入请求。
- 会话可并行；切换视图不取消任务；同项目共享目录，显示并行提示。
- 展示父会话派发的子代理名称、角色、状态，支持只读查看子会话。
- Git 只读展示工作区状态与 diff（含已暂存/未暂存）；不做 Git 写操作按钮。
- 不做通用文件浏览。
- 左栏项目/会话，右侧可展开检查面板，标签切换子代理与 Git diff；手机用抽屉。未来文件功能可扩展为右侧标签。
- 提供 CodexWeb 命令，启动服务并调用 Android 浏览器打开 localhost。
- 运行中支持 steer；follow-up 排队等当前任务结束再发送，队列状态可见。
- 支持实际实现的斜杠命令菜单与 $skills 搜索/插入，用协议中的技能输入调用。

## 架构

浏览器界面 → localhost Node HTTP / SSE → 本机 Codex app-server（stdio）。用版本匹配的协议实现小型客户端，复用已有 Codex 登录与配置；不再额外安装附带另一份 CLI 的 SDK。依赖保持轻量，无需 Ubuntu、数据库或构建工具。

Codex 自身保存会话历史；本应用只保存项目列表。Node 持有并发请求、执行状态、待审批请求和短期事件重放。浏览器重连后重读会话并同步未完成执行，任务生命周期独立于网页连接。

## 验证

测试 RPC 并发分发、审批关联、会话状态、事件重连、路径/请求边界与只读 Git；用本机 app-server 验证握手、历史读取和最小真实对话。启动页面后检查 HTTP 资源与移动布局；若当前环境没有浏览器，明确记录真机视觉验证限制。
